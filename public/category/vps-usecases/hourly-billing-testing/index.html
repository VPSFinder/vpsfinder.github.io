    按小时计费怎么算 #

    按小时计费的云服务器一般需要先充值余额，开机后按运行时长从余额中扣费，每月设有封顶价。比如 Vultr 每月按 672 小时封顶，跑满一个月也不会超过标注的月价，用几个小时就只付几个小时：

    • 开机即扣费：按实际存在的小时数计算；
    • 每月有封顶：跑满整月等于标注月价；
    • 销毁才停扣：关机通常仍会计费。

    最容易踩的坑是“关机不等于停止计费”。Vultr 等云服务商对关机状态的实例照常收费，因为硬盘和 IP 仍然被你占用，只有销毁实例才会停止扣费，测试结束后记得到控制台确认实例已删除。

    常见问题解答 #

    按小时计费的 VPS 关机还扣费吗？ #

    大多数会继续扣费。关机后硬盘和 IP 仍然为你保留，Vultr 等云服务商会照常按小时计费，只有销毁实例才会停止扣费。测试结束后，记得到控制台确认实例已经删除。

    按小时计费的 VPS 能用来换 IP 吗？ #

    可以。删除实例再新建一台，通常会分配到新的 IP，这是按小时计费最常见的用途之一。不过同一机房的 IP 段相近，遇到整段被封的情况，换到其他机房的效果会更好。

    按小时计费和年付哪个便宜？ #

    短期用按小时计费便宜，长期用年付便宜。按小时计费跑满一个月等于标注月价，一年下来通常比年付特价机贵一倍以上。使用超过三个月、配置也确定了，就值得换成年付机型。

    余额用不完可以退吗？ #

    各家规则不同。CloudCone 删机后余额保留在账户里，可以继续用于下次开机；Vultr 的体验金有使用期限，到期未用完的部分会失效。充值前建议按测试需要少量多次充值，避免余额闲置。

    按小时计费的 VPS 适合建站吗？ #

    可以，但不划算。网站需要长期在线，按小时计费跑满一年的费用通常高于年付机型。更合适的做法是先用按小时计费的机器把网站搭好、测完，再迁移到年付主机上长期运行。
