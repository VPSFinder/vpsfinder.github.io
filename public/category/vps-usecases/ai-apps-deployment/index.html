    AI 服务的地区限制 #

    OpenAI、Anthropic 与 Google 的 AI 服务都有支持地区列表，中国大陆和香港都不在其中。不只是网页版，API 调用同样会检查请求来源，服务器放错地区，程序写得再好也会直接报错：

    • 美国机房：三大 AI 普遍可用，首选；
    • 日本、新加坡：在官方支持地区内；
    • 香港机房：主流 AI 服务均不可用。

    我们在香港机房实测，Gemini 与 Claude 都不可用，ChatGPT 仅手机 App 可用，所以香港机型再便宜、延迟再低，也不适合部署 AI 应用。美国机房是最稳妥的选择，站内实测的美国机型大多三大 AI 全部可用。

    不过“可用”也有差别。Vultr 洛杉矶实测 Gemini 不可用，部分 IP 风险评分偏高的机型，登录网页版时更容易触发验证。只调用 API 影响不大，需要长期登录网页版账号的，可以考虑住宅 IP 机型。

    AI 应用需要多大配置 #

    调用 API 的应用，计算都在 AI 厂商的服务器上完成，VPS 只负责收发请求，配置要求很低。真正需要算力的，是在 VPS 上自己运行模型，常见的几类应用需求差别很大：

    应用类型典型工具建议配置说明
    聊天机器人Telegram / Discord 机器人1核1G只转发 API 请求
    网页前端Open WebUI、LobeChat1核1G 至 2GB多人使用时加内存
    自动化工作流n8n2GB 起工作流多时加内存
    知识库应用Dify2核4G 起多个容器同时运行
    本地运行模型Ollama8GB 起或 GPU7B 模型约需 8GB 内存

    Dify 官方要求至少 2 核 CPU 与 4GB 内存，它由近十个 Docker 容器组成，内存给少了会频繁崩溃。n8n 本身很轻，但工作流和执行记录多了以后内存会逐渐上涨，2GB 是比较稳妥的起点。

    在纯 CPU 的 VPS 上运行本地模型，按 Ollama 的说明，7B 模型至少需要 8GB 内存，13B 模型需要 16GB，而且生成速度很慢。真要自己跑模型，建议选带 GPU 的云服务器；只是做应用的话，调用 API 更省心也更便宜。

    AI 应用VPS选型建议 #

    选 AI 应用 VPS 时，先想清楚你的应用是只调用 API，还是要在服务器上做更多事：只调用 API 的优先看价格和 AI 可用性，要跑多容器应用、本地模型或网页版账号的，再按需求选性能、GPU 或住宅 IP。

    只调用 API 的轻量应用 #

    如果你部署的是聊天机器人、网页前端或简单的自动化脚本，服务器只负责转发请求，那么 AI 可用性和价格比配置更重要。按付款方式和应用规模，可以这样选：

    • 机器人与前端，年付最省：RackNerd 特价年付
    • n8n 工作流，月付灵活：Evoxt 美国 VPS

    RackNerd 年付最便宜，三大 AI 实测全部可用，适合长期挂着的机器人；Evoxt 单核性能更强，按月付费，适合工作流较多、偶尔需要调整配置的用户。

    多容器应用与特殊需求 #

    如果你要搭建 Dify 知识库、自己运行模型，或者需要长期登录网页版账号，那么性能、GPU 或 IP 属性往往比单价更重要。按具体需求，可以这样选：

    • Dify 等多容器应用：GreenCloud Ryzen VPS
    • 运行或微调模型：Vultr GPU 实例
    • 网页版账号与自动化：iPRaft 原生双 ISP

    GreenCloud 单核性能最高，适合多容器应用；Vultr 的 GPU 实例按小时计费，适合短期测试模型；iPRaft 住宅 IP 风险评分干净，适合需要长期登录账号的场景，但硬件性能一般。

    常见问题解答 #

    为什么香港 VPS 用不了 ChatGPT？ #

    OpenAI、Anthropic 与 Google 都没有向中国大陆和香港开放服务，会根据请求来源的 IP 判断地区。我们在香港机房实测，Gemini 与 Claude 不可用，ChatGPT 仅手机 App 可用，部署 AI 应用要选美国、日本或新加坡机房。

    调用 AI API 需要多大配置的 VPS？ #

    很小。调用 API 时计算都在 AI 厂商那边完成，VPS 只收发请求，1核1G 就能跑聊天机器人和网页前端。需要更多配置的是 n8n、Dify 这类应用本身，以及在服务器上自己运行模型。

    VPS 上能跑本地大模型吗？ #

    能跑，但体验一般。纯 CPU 的 VPS 运行 7B 模型至少需要 8GB 内存，生成速度也比较慢，适合测试和学习。需要流畅使用或者跑更大的模型，建议选按小时计费的 GPU 实例，用完就删。

    API 密钥放在 VPS 上安全吗？ #

    只要做好基本防护就比较安全：密钥放在环境变量或配置文件里，不要提交到公开的代码仓库；服务器修改默认 SSH 端口、关闭密码登录；在 AI 厂商后台设置用量上限，万一泄露也能控制损失。

    用 VPS 访问 AI 服务违反规定吗？ #

    AI 厂商要求在其支持的地区使用服务，并遵守各自的使用条款。部署自己的应用、在支持地区调用 API 是常见用法，但把 API 转售给他人、批量注册账号等行为可能违反条款，使用前建议阅读各家的服务协议。
