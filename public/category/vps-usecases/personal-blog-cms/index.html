    个人博客VPS推荐：WordPress、Typecho 与 Hugo 需要多大配置 #

    个人博客是最常见、也最容易买过头的 VPS 用途。日访问几百人的博客，对 CPU 和带宽的要求都很低，真正影响体验的是建站程序吃多少内存，以及机房离你的读者有多远。

    这篇文章先讲清 WordPress、Typecho 与 Hugo 三种程序各需要多大配置，再推荐五家适合博客的商家：年付入门、香港免备案、月付轻量、可升级优化线路与大内存机型，每家都附上套餐表。

    博客程序需要多大配置 #

    决定博客配置的主要是建站程序，而不是访问量。动态程序每次访问都要执行 PHP 并查询数据库，静态程序只是把生成好的网页文件发给读者，两者对内存的要求可以差好几倍：

    建站程序运行环境建议内存适合谁
    WordPressPHP + MySQL / MariaDB1GB 起，插件多选 2GB想要现成主题与插件的博主
    TypechoPHP + SQLite 或 MySQL512MB 足够只想写字、喜欢简洁的博主
    Hugo本地生成，服务器只跑 Nginx512MB 足够熟悉 Markdown 与 Git 的博主

    WordPress 本身不重，吃内存的是 MySQL 与插件。1GB 内存装好缓存插件、再开一点 Swap 就能稳定运行；装了页面构建器、电商或多语言插件，建议直接上 2GB，后台会顺畅很多。

    Typecho 可以用 SQLite 存数据，省掉一个常驻的数据库进程，512MB 内存也很宽裕。Hugo 则在你自己的电脑上生成网页，服务器只负责分发静态文件，最便宜的机型就够用。

    带宽、流量与硬盘 #

    个人博客的流量通常很小，一篇带几张图的文章约 1~2MB，每月 1TB 流量可以支撑几十万次页面访问。图片较多时，把图片交给 CDN 或对象存储，比升级带宽更划算。

    硬盘方面，WordPress 程序加数据库通常不到 1GB，20GB 已经能放很多年的文章和图片。真正需要留意的是备份：选有快照或自动备份的商家，比单纯追求大硬盘更实用。

    机房与线路怎么选 #

    配置定下来之后，机房位置决定读者打开网页快不快。博客场景下主要看读者在哪里，再结合预算决定要不要为回国线路多花钱，常见的选择可以分为三类：

    • 香港机房：国内延迟低，无需备案；
    • 美国普通线路：价格最低，配合缓存使用；
    • 美国优化线路：晚高峰稳定，价格更高。

    读者主要在国内，又不想办理 ICP 备案，香港机房是最直接的方案，站内实测的香港机型华南延迟只有 20 多毫秒。美国机房价格低得多，但普通线路国内延迟在 150ms 以上，晚高峰还会更高。

    美国普通线路搭配页面缓存和 CDN，对文字为主的博客影响并不大；如果你很在意晚高峰的打开速度，可以考虑 CN2 GIA 等优化线路，详见 美国CN2 GIA VPS推荐。

    博客VPS选型建议 #

    选博客 VPS 时，先想清楚读者主要在国内还是海外：读者在国内的优先看机房和线路，读者分布广或者更在意预算的，优先看价格与配置。下面按这两类分别给出建议。

    读者主要在国内 #

    如果你的博客面向国内读者，打开速度会直接影响阅读体验、跳出率和搜索排名，那么机房位置和回国线路就是第一优先级。按预算和对晚高峰的要求，可以这样选：

    • 免备案，国内延迟最低：野草云香港特惠年付
    • 先买入门，再升级线路：搬瓦工 Basic VPS

    野草云香港机型国内延迟最低，适合大多数中文博客；搬瓦工 Basic 价格适中，后台功能完善，博客流量起来后可以升级到 CN2 GIA-E 线路，不用重新找商家。

    看重价格与配置 #

    如果你的读者分布在海外，或者博客以文字为主、对打开速度没那么敏感，那么价格和配置往往比线路更重要。按付款方式和内存需求，可以这样选：

    • 一年只花二十多美元：RackNerd 特价年付
    • 按月付费，自带备份：Evoxt 月付 VPS
    • 多个站点，内存优先：GreenCloud 特价年付

    RackNerd 年付最便宜，适合第一次建站练手；Evoxt 按月付费、单核性能强，适合想灵活停用的读者；GreenCloud 内存最大，但特价机不退款，下单前要确认自己的需求。

    常见问题解答 #

    WordPress 博客用 1G 内存够吗？ #

    够用。1GB 内存跑 WordPress、Nginx 与 MySQL，装好缓存插件后可以稳定运行，再开 1GB Swap 能避免流量突增时进程被系统终止。插件很多或要跑电商功能时，建议选 2GB。

    用香港或美国 VPS 建站需要备案吗？ #

    不需要。ICP 备案针对的是中国大陆境内的服务器，香港和美国机房都不在备案范围内，买来即可绑定域名建站。代价是不能使用国内 CDN 节点加速，读者在国内时机房位置更重要。

    美国VPS建博客，国内打开慢怎么办？ #

    先开启页面缓存，把图片交给 CDN 或对象存储，文字为主的博客体验会明显改善。仍然觉得慢的话，可以换香港机房，或者升级到 CN2 GIA 优化线路，晚高峰的打开速度会稳定很多。

    Hugo 博客还需要买 VPS 吗？ #

    不一定。Hugo 生成的是纯静态网页，可以免费托管在 GitHub Pages 等平台。买 VPS 的好处是能自己控制服务器配置、绑定多个站点，也方便以后部署评论系统或其他服务。

    新手装宝塔面板会不会太占内存？ #

    宝塔、1Panel 这类面板本身也要占用内存，在 512MB 机型上会比较吃紧。新手想用面板，建议直接选 1GB 以上内存；熟悉命令行的话，手动安装 Nginx 与 PHP 更省资源。
