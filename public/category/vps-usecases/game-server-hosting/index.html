    游戏服务器需要多大配置 #

    游戏服务端最吃的是内存和单核性能。多数游戏的主逻辑跑在一个线程上，核心再多也帮不上忙，CPU 单核越快，同屏实体和红石机器越多时越不容易卡。不同游戏的需求差别很大：

    游戏建议内存主要压力默认端口
    我的世界 Java 版原版 2~4GB，模组 6GB 起单核性能、内存TCP 25565
    幻兽帕鲁8GB 起，人多选 16GB内存、CPUUDP 8211
    泰拉瑞亚1~2GB单核性能TCP 7777
    饥荒联机版2GB 起（地上加洞穴）单核性能UDP 10999 起

    我的世界原版十人以内，2~4GB 内存就能流畅运行；装了大型模组包，6~8GB 是起点。插件服推荐用 Paper 等优化服务端，同样的配置能多承载不少玩家，区块预生成也能明显减少卡顿。

    幻兽帕鲁的专用服务器非常吃内存，长时间运行后占用还会逐渐上涨，8GB 只适合几个人游玩，人多或者想长期不重启，建议直接选 16GB。泰拉瑞亚和饥荒则很轻，1~2GB 的入门机型就足够。

    带宽没那么重要 #

    游戏服务器传的是玩家的坐标和操作指令，十个人同时在线，上行带宽通常也只要几 Mbps。真正影响体验的是延迟和丢包：丢包会让玩家瞬移、回弹，比延迟高几十毫秒更让人难受，所以选机型时要优先看丢包表现。

    机房与线路怎么选 #

    玩家主要在国内时，机房离得越近越好。游戏对延迟的敏感度远高于网页，100ms 和 200ms 的差别玩家能明显感受到，选机房可以按下面三类对照：

    • 香港机房：国内延迟 20~60ms，体验最好；
    • 日本机房：延迟 30~60ms，配置更便宜；
    • 美国机房：延迟 150ms 以上，只适合休闲玩法。

    香港机房的延迟最低，但带宽成本高，大内存机型往往不便宜；日本机房到国内通常在 30~60ms，具体取决于线路，同样的预算能买到更大的内存，适合幻兽帕鲁这类吃内存的游戏。各地区线路对比见 香港VPS推荐 与 日本VPS推荐。

    美国机房延迟偏高，但并非不能玩：建造、种田类的休闲玩法对延迟不敏感，玩家里有海外朋友时，美西机房反而是兼顾两边的选择。PVP 和动作类玩法则建议坚持选亚洲机房。

    常见问题解答 #

    我的世界服务器要多大内存？ #

    原版服十人以内 2~4GB 就够，插件服按插件数量适当增加；大型模组包建议 6~8GB 起。内存不是越大越好，分配过多反而可能让 Java 垃圾回收变慢，按玩家数和模组数量配置即可。

    幻兽帕鲁服务器 8GB 内存够吗？ #

    几个人短时间游玩基本够用，但帕鲁服务端运行时间越长，内存占用越高，8GB 很容易被吃满导致卡顿或崩溃。人多或想长期不重启，建议选 16GB，并设置每天定时重启。

    开服后朋友连不上怎么办？ #

    先检查服务器防火墙和商家控制台的安全组是否放行了游戏端口，注意区分 TCP 与 UDP；再确认服务端监听的是公网地址而不是 127.0.0.1。大多数连不上的问题，都出在端口没有放行。

    游戏服务器选 Windows 还是 Linux？ #

    优先选 Linux。主流游戏的专用服务端都支持 Linux，占用资源更少，同样的配置能承载更多玩家。只有少数游戏的服务端只提供 Windows 版本，或者你需要图形界面管理时，才考虑 Windows 系统。

    存档怎么备份？ #

    至少每天备份一次世界存档到另一台机器或本地电脑，大版本更新和安装新模组前再手动备份一次。支持快照的商家可以额外做整机快照，但快照和服务器在同一个机房，不能替代异地备份。
