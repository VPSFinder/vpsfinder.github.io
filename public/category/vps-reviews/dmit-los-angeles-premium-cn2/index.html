    DMIT 洛杉矶 Premium 测评：三网 CN2 GIA 回程、全国平均 164ms、持续 Ping 0 丢包与 EPYC 9654 跑分实测 #

    DMIT 的洛杉矶 Premium 线路（官网现在标注为 Pro）是美西 CN2 GIA 里的高端选择，价格比普通线路贵出好几倍。大家最想知道的是，这个价格换来的晚间稳定性到底有多好，硬件和解锁又配不配得上这个价位。

    这次我们开通了一台 DMIT 洛杉矶 Premium 1核2G 实例，从延迟、丢包、路由、硬件、带宽和 IP 属性六个维度做了完整测试。延迟与丢包两项使用 DMIT 官方 Looking Glass 公布的洛杉矶 Pro 测试 IP 测得，其余数据均来自测试机本身。

    先给赶时间的读者一个结论：这台机器的强项是回国线路，三网回程都从 CN2 GIA 回国，持续 Ping 全部 0 丢包，到上海的带宽也能跑到 860Mbps；短板是价格高、25 端口被封，Netflix 只能看自制剧。

    测试机型与测试环境 #

    本次测试的实例为 DMIT 洛杉矶 Premium 线路的 1核2G 款，配置与在售的 LAX.AS3.Pro.TINY 相同。以下配置均以系统内 lscpu、free、df 命令与 Bench.sh 的实际识别结果为准：

    • 处理器：AMD EPYC 9654 96-Core，分配 1 个 vCPU
    • 内存与存储：1.9GB 可用内存与 1GB Swap，20GB 系统盘
    • 网络：IPv4 与 IPv6 双栈，归属 AS906 DMIT
    • 测试系统：Ubuntu 22.04 LTS，内核 6.8，已开启 BBR

    AS906 是 DMIT 自己的自治系统，测试机上线时已连续运行 125 天，负载很低。延迟与丢包两项改用官方测试 IP 179.255.100.100，它与测试机同属洛杉矶 West 7 Center 机房的 Pro 线路。

    国内三网延迟实测 #

    美西机房到国内的物理延迟在 130ms 左右，精品线路的价值在于尽量不绕路、少排队。我们使用 ITDOG 调用全国 319 个监测节点，对 DMIT 洛杉矶 Pro 的官方测试 IP 发起了三网延迟测试：

    全国平均延迟为 164ms，三网分别为电信 163ms、联通 165ms、移动 165ms，三家几乎没有差距。最快的是上海电信 126ms，上海联通与上海移动也都是 130ms，全国地图整片处在 101~200ms 的浅绿区间。

    按地区看，华东平均只有 144ms，华南、华中、华北都在 165~169ms，西南、西北、东北在 173~176ms。唯一的异常值是河南安阳电信 420ms，属于单个节点的波动，不影响整体判断。

    持续丢包监测 #

    延迟之外，持续丢包更能反映线路的实际可用性。我们使用 ping.pe 从国内 13 个节点对官方测试 IP 连续发起 100 次 Ping，覆盖三网运营商以及腾讯云、阿里云的机房出口：

    13 个节点连续 100 次 Ping 全部 0% 丢包，云厂商出口与三网运营商节点都没有出现一次丢包。平均延迟最低的是上海腾讯云 131ms、南京腾讯云 133ms，江苏三网都在 143~144ms，最高的广州腾讯云也只有 165ms。

    延迟波动同样很小，多数节点的标准差在 0.02~0.07ms 之间，波动最大的丽水联通也只有 1.62ms。三网运营商节点之间差距不到 10ms，没有出现某一家明显掉队的情况，这与三条回程都走 CN2 GIA 的路由结果一致。

    这样的稳定性正是 Premium 线路贵的原因。普通线路在晚间常见的 5%~20% 丢包，在这里基本看不到，访客集中在晚上的网站和需要长时间保持连接的业务，体验差距会非常明显。

    三网回程路由追踪 #

    我们在测试机上用 tracepath 分别追踪了到国内电信、联通和移动三个目标地址的回程路径：

    • 电信目标：出口第 7 跳进入 59.43 CN2 GIA，159ms 到达
    • 联通目标：经 CN2 GIA 后转入联通骨干，181ms 到达
    • 移动目标：全程 CN2 GIA 后进入移动网，143ms 到达

    三条路径离开洛杉矶后的第一跳都是 59.43 开头的电信 CN2 GIA 节点，出国段延迟稳定在 126~127ms，联通和移动目标是在国内段才转入各自的网络。也就是说，这台机器三网回程都享受到了 CN2 GIA 的优先保障。

    需要说明的是，DMIT 官网介绍洛杉矶机房同时与联通 AS9929、移动 AS58807 对等互联，本次测得的三条回程都从 CN2 GIA 回国，线路可能随商家调度变化。联通用户如果更在意晚间带宽，下单前可以先用官方 Looking Glass 测试自己的线路。

    EPYC 9654 是 AMD 第四代 EPYC 的 96 核旗舰，单核 Sysbench 得分 4,229 events/s，比 搬瓦工纽约 USNY_6 的 3,254 高出约三成，低于 Evoxt 洛杉矶的 5,645。跑建站、反向代理和日常开发都很宽裕。

    磁盘方面，FIO 4K 随机写达到 29.3k IOPS，4K 随机读约 2,149 IOPS，读的数字明显低于写，日常建站对随机读的压力不大，影响有限。Bench.sh 三轮连续写入分别为 741、875、901 MB/s，平均 839 MB/s。

    IP 属性与流媒体解锁 #

    最后我们检测了测试机的 IP 质量与常见服务的解锁情况。IP 质量部分使用 IPQuality 脚本，汇总了 Maxmind、IPinfo、Scamalytics 等多个数据库的判定：

    • IP 类型：AS906 原生 IP，位于洛杉矶，注册地美国
    • 使用类型：五个数据库均判定为机房
    • 风险评分：Scamalytics 0、IP2Location 3、AbuseIPDB 0
    • 偏高项：IPQS 84 分可疑，并标记代理与 VPN

    除 IPQS 外，其余数据库都给出了低风险，整体 IP 信誉在机房 IP 里属于干净的一类。邮件方面，本地 25 端口出站被阻断，在 439 个有效黑名单数据库中有 59 个标记、2 个收录，不适合用来自建邮局。

    流媒体与 AI 服务方面，YouTube Premium、Amazon Prime Video、TikTok 与 Spotify 均可解锁美区，YouTube CDN 就在洛杉矶。Netflix 只能观看自制剧，Disney+ 显示 IP 被封禁，Dazn 与 Reddit 也无法使用。

    AI 服务全部可用，ChatGPT、Google Gemini 与 Claude 都能正常访问，Google 搜索也没有弹出验证码。对于需要调用 AI 接口、又希望国内访问速度快的开发者来说，这台机器能同时满足两边的需求。

    常见问题解答 #

    DMIT 洛杉矶 Premium 是 CN2 GIA 线路吗？ #

    是。本次 tracepath 显示，到电信、联通、移动三个目标的回程都先进入 59.43 开头的 CN2 GIA 节点，出国段延迟稳定在 126~127ms。官网介绍还与联通 9929、移动 CMI 互联，实际走哪条以调度为准。

    DMIT 洛杉矶晚上会卡吗？ #

    从持续 Ping 的结果看不会。国内 13 个节点连续 100 次 Ping 全部 0 丢包，延迟波动不到 1ms，全国 319 个节点平均 164ms。访客集中在晚上的网站，是最能体现 Premium 线路价值的场景。

    DMIT 能看 Netflix 和用 ChatGPT 吗？ #

    ChatGPT、Gemini 与 Claude 都能正常使用，YouTube Premium、Prime Video 与 TikTok 也能解锁美区。Netflix 只能观看自制剧，Disney+ 显示 IP 被封禁，主要用来看流媒体的话需要另外考虑。

    DMIT 洛杉矶适合自建邮局吗？ #

    不适合。本地 25 端口出站被阻断，远端 25 端口不可达，IP 还被 2 个黑名单数据库收录。需要发送通知邮件的网站，建议使用第三方 SMTP 服务；需要自建邮局的话，可以参考 VPS自建邮件进垃圾箱怎么办。

    DMIT 入门款买不到怎么办？ #

    洛杉矶 Pro 的入门款经常缺货，可以先留意官网补货，或者看规格更高的 Pocket 款。急需上线的话，同样有 CN2 GIA 线路的 搬瓦工 现货更充裕，可以作为替代。

    适用场景与选购建议 #

    综合六个维度的实测，DMIT 洛杉矶 Premium 的定位非常清晰：它把钱花在了回国线路上，三网 CN2 GIA 回程、持续 0 丢包和接近满速的回国带宽，在美西机房里都属于顶尖水平，代价是价格高、库存紧。

    适合的用户与业务：

    • 访客在国内、在意晚间速度的网站与独立站
    • 需要稳定长连接的远程办公与开发环境
    • 既要国内访问快、又要用 AI 服务的开发者

    不太适合的用户与业务：

    • 预算有限、只想要一台便宜美国机器的用户
    • 需要自建邮局或依赖 25 端口的业务
    • 主要用来看 Netflix、Disney+ 的流媒体需求
