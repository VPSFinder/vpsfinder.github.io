    测试机型与测试环境 #

    本次测试的实例为 Kamatera 洛杉矶机房的 1核1G 机型。以下配置均以系统内 lscpu、free、df 与 Bench.sh 的实际识别结果为准，而非套餐页上的标称值：

    • 处理器：Intel Xeon Processor（Sapphire Rapids）@ 2.70GHz，分配 1 个 vCPU
    • 内存与存储：956MB 可用内存，未配置 Swap，20GB 系统盘
    • 网络：独立 IPv4，归属 AS36007 Kamatera, Inc.，Bench.sh 定位在雷东多海滩
    • 测试系统：Ubuntu 22.04.5 LTS，内核 5.15，默认 cubic 拥塞控制，未开启 BBR

    所有测试于 2026 年 2 月 2 日完成，硬件、带宽与 IP 检测在北京时间 20:44 至 21:01 的晚高峰进行。本次未进行内存吞吐测试，Backtrace 也未输出结果，因此没有回程路由章节。

    带宽与下载速度 #

    带宽是 Kamatera 最突出的卖点，所以放在最前面。

    本地测速节点下载 13,750 Mbps、上传 11,772 Mbps，确实兑现了万兆级端口。远程方向中，巴黎下载 5,461 Mbps，阿姆斯特丹、东京与新加坡也都在 4.5 Gbps 左右，下载能力非常惊人。

    上传到远端的速度则大多在 680 到 890 Mbps 之间。到苏州与宁波的下载仍有 2,000 Mbps 以上，但上传只有 1 Mbps 左右，香港节点上下行都低于 3 Mbps，洛杉矶与达拉斯节点测试失败。

    Sapphire Rapids 是英特尔第四代至强可扩展处理器，单核 Sysbench 得分 2,692 events/s，大约是老一代 E5、Broadwell 平台的 3 倍，跑 WordPress 动态页面或轻量 API 都很从容。

    磁盘测试采用 psync 引擎与单队列深度，4K 随机混合读写未绕过系统缓存，各约 7,850 IOPS；1M 顺序读写仅用 0.25 秒完成，也可能命中了缓存。Bench.sh 三轮写入平均 1,399.5 MB/s。

    国内三网延迟实测 #

    我们使用 ITDOG 调用全国 159 个监测节点，对这台实例发起了三网 ICMP 延迟测试：

    全国平均延迟为 204ms，三网分别为电信 197ms、联通 196ms、移动 222ms。最快的是江苏南通电信 155ms 与湖北武汉联通 157ms，最慢的河南郑州联通达到 285ms，华北、西北与东北平均都超过 200ms。

    根据我们的观察，晚高峰时段全国平均延迟会上升到 220ms 左右。这是典型的美西非优化线路水平，比走 CN2 回程的洛杉矶机器要慢 40ms 以上，国内访客能明显感受到差距。

    丢包是这台机器面向国内的最大问题。只有江苏移动、江苏联通与丽水联通为 0%，江苏电信高达 19%，丽水移动 17%、丽水电信 16%，大部分云厂商节点也在 7% 到 14% 之间。

    IP 属性与流媒体解锁 #

    最后我们检测了这台实例的 IP 质量与常见服务解锁情况。IP 质量部分使用 IPQuality 脚本，汇总了 Maxmind、IPinfo、Scamalytics 等多个数据库的判定：

    该 IP 在 Maxmind 中被识别为美国加州的原生 IP，各大数据库的使用类型均标记为机房。IP2Location、ipapi 与 AbuseIPDB 为低风险，但 Scamalytics 给出 57 分中风险。

    IPQS 给出 75 分可疑评级，并将其判定为代理与 VPN。大厂云 IP 普遍存在这种情况，对于需要注册风控严格平台账号的用户来说，这一点需要特别注意。

    邮件方面，本地 25 端口出站可用，能连通 Gmail、Outlook、Yahoo、QQ 与 163 等邮箱，只有 GMX、Mail.com 与搜狐不通。但在 439 个有效黑名单数据库中，有 44 个已标记、2 个将其列入黑名单，自建邮局前最好先检查自己分到的 IP。

    流媒体方面，Netflix、YouTube Premium、Amazon Prime Video 与 TikTok 均可解锁美区，TVBAnywhere+ 也可解锁。不过 Disney+ 显示 IP 被封禁，Reddit 与 Spotify 也无法使用。

    AI 服务全部可用，ChatGPT、Google Gemini 与 Claude 均能正常访问。配合万兆级带宽，它也适合用来跑需要大量调用 AI 接口或下载模型的开发任务。

    Kamatera 真的有万兆带宽吗？ #

    有。Bench.sh 本地节点实测下载 13,750 Mbps、上传 11,772 Mbps，到巴黎、东京、新加坡的下载也在 4.5 Gbps 以上。但到国内与香港方向的上传只有个位数 Mbps。

    Kamatera 洛杉矶适合国内访问吗？ #

    不适合。全国三网平均 204ms，14 个节点中 11 个有丢包，最高达到 19%，晚高峰会更严重。如果访客主要在国内，建议选择提供 CN2 回程的美国机房。

    Kamatera 能发邮件吗？ #

    可以。本次实测 25 端口出站可用，能连通 Gmail、Outlook、QQ 等主流邮箱。不过 IP 在 2 个黑名单数据库中被收录，正式发信前建议先查询分配到的 IP。

    Kamatera 能用 ChatGPT 和 Gemini 吗？ #

    可以。ChatGPT、Google Gemini 与 Claude 均可正常访问，Netflix、YouTube Premium 与 Prime Video 也能解锁美区，但 Disney+ 显示 IP 被封禁。
