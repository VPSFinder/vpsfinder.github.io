    测试机型与测试环境 #

    本次测试的实例为 HostDare 洛杉矶 CN2-GIA 线路的早期入门机型，规格与现售的 CSSD1 不同。以下配置均以系统内 lscpu、free 与 df 命令的实际识别结果为准：

    • 处理器：Intel Core Processor (Broadwell)，1 个 vCPU，2.59GHz
    • 内存与存储：717MB 可用内存，256MB Swap，10GB 系统盘
    • 网络：独立 IPv4，归属 AS40065 CNSERVERS，位于洛杉矶
    • 系统：Ubuntu 22.04，已开启 BBR，开测时已连续运行 246 天

    回程路由、IP 质量与解锁检测于 2025 年 10 月 19 日北京时间 22:44 至 22:51 采集，正好处在晚高峰后段；Bench.sh 于 11 月 4 日北京时间 21:50 前后运行。三网延迟与持续 Ping 的截图未保存采集日期。

    国内三网延迟实测 #

    美西机房到国内的物理延迟在 130ms 左右，优化线路的价值主要体现在三网是否均衡、偏远地区会不会掉队。我们使用 ITDOG 调用全国 162 个监测节点，对这台实例发起了三网 ICMP 延迟测试：

    全国平均延迟 168ms，三网分别为电信 165ms、联通 169ms、移动 170ms，差距只有 5ms。最快的是上海移动 132ms，江苏苏州电信与上海联通都是 136ms，华东地区平均 153ms，全国地图各省份都处在 101ms 到 200ms 的区间。

    最慢的节点集中在偏远地区，新疆乌鲁木齐移动 228ms、西藏拉萨移动 215ms，西北地区平均 188ms。整体来看，HostDare 的延迟比 TmhHost 洛杉矶 CN2 的三网平均 159ms 略高，但同样属于美西优化线路的正常水平。

    持续丢包监测 #

    我们从 14 个国内节点对实例连续发起 100 次 Ping，覆盖江苏、湖北、浙江丽水的三家运营商节点，以及腾讯云、阿里云和华为云的出口，截图时间轴为 17:25 至 17:28：

    6 个运营商节点的丢包率全部为 0%，平均延迟方面，江苏电信 142ms、丽水移动 144ms、丽水电信 148ms，湖北联通与江苏移动在 173ms 到 175ms 之间。丽水三网出现过 296ms 到 455ms 的单次峰值，标准差 14ms 到 31ms，属于个别监测点的瞬时波动。

    丢包主要出现在云厂商节点：青岛阿里云 17%、广州腾讯云 16%、成都腾讯云 11%，其余云节点在 0 到 2% 之间。云厂商出口的国际线路与家庭宽带不同，这部分结果更适合作为参考，而不是判断线路质量的主要依据。

    三网回程路由追踪 #

    我们使用 Backtrace 对北京、上海、广州、成都四地三网进行了回程检测：

    四地电信全部被识别为电信 CN2 优质线路，北京、上海、广州三地联通走联通 9929 精品网，只有成都联通走 4837 普通线路。移动方向四地都走移动 CMI，脚本将其归为普通线路，官网标注的 CMIN2 没有在本次检测中出现。

    需要说明的是，Backtrace 只能识别出 CN2，无法进一步区分 GIA 与 GT，本次也没有追踪国内到洛杉矶的去程路由。结合延迟表现看，电信与联通用户的体验最好，移动用户的延迟虽然也能做到 170ms，但晚高峰的稳定性不如前两者有保障。

    单核 Sysbench 得分 1,039 events/s，高于 TmhHost 洛杉矶 CN2 的 796，跑博客、企业官网与反向代理等轻量应用没有问题，但不适合编译、转码等计算密集型任务。

    磁盘测试采用 libaio 引擎与单队列深度，未加 --direct 参数。在这一前提下，4K 随机写 94,000 IOPS 主要反映的是系统缓存速度；4K 随机读 5,634 IOPS 更接近磁盘的真实水平，Bench.sh 三轮顺序写入平均 858.7 MB/s。

    还要注意存储空间：这台早期机型只有 10GB 系统盘，开测时已用掉 7.9GB。现售 CSSD1 已经升级到 25GB NVMe，放一个 WordPress 站点和日常备份会从容很多。

    香港节点只有 4~5Mbps，与其他节点差距明显。本地测速也远高于官网 CSSD 系列标称的 50~100Mbps，由于本次没有用国内家庭宽带做 iperf3 测试，回国方向的实际可用带宽请以官网套餐标称为准。

    IP 属性与流媒体解锁 #

    最后我们检测了这台实例的 IP 质量与常见服务解锁情况。IP 质量部分使用 IPQuality 脚本，汇总了 Maxmind、IPinfo、IPQS 等多个数据库的判定：

    该 IP 在 Maxmind 中定位为美国洛杉矶，但注册地为新加坡，属于广播 IP。IPinfo、ipregistry、ipapi、IP2Location 与 AbuseIPDB 五个数据库的使用类型全部判定为机房，这是一个典型的数据中心 IP。

    风险评分两极分化：IP2Location 3 分、ipapi 0.39%、AbuseIPDB 0 分，均为低风险；IPQS 却给出 100 分高风险，并标记了代理、VPN、滥用与机器人，其余数据库在这些风险因子上均为“否”。

    邮件方面，本地 25 端口出站被阻断，远端 25 端口也不可达，无法直接自建邮局发信。在 439 个有效黑名单数据库中，有 30 个已标记、1 个将其列入黑名单。

    流媒体方面，YouTube Premium、Amazon Prime Video 与 Spotify 均为美区可用，TikTok 也能解锁；Netflix 仅能观看自制剧，Disney+ 显示 IP 被封禁。YouTube 与 Netflix 的 CDN 都位于洛杉矶，Bing 地区为美国但标注为 Risky。

    AI 服务全部可用，ChatGPT、Google Gemini 与 Claude 均能正常访问，Google 搜索也没有出现验证码。用作访问 AI 服务的开发环境没有问题，但不适合对 IP 风控要求严格的账号运营。

    常见问题解答 #

    HostDare 洛杉矶是 CN2 GIA 线路吗？ #

    Backtrace 识别出四地电信回程全部走 CN2，但工具无法区分 GIA 与 GT，本次也没有追踪去程路由。官网标注为 CN2 GIA，从电信平均 165ms、运营商节点 0 丢包的表现看，电信方向的线路质量是有保障的。

    移动用户适合买 HostDare 吗？ #

    可以用，但不是它的强项。本次四地移动回程都走 CMI，没有检测到官网标注的 CMIN2，全国移动平均延迟 170ms，与电信差距不大。如果网站访客以移动用户为主，更建议选择三网都走精品网的 DMIT。

    IPQS 100 分会影响使用吗？ #

    对建站和 API 服务基本没有影响，ChatGPT、Gemini 与 Claude 都能正常访问。但 IPQS 被不少平台用于风控，如果要用这台机器登录电商、社媒等对 IP 敏感的账号，就容易触发验证，这类需求建议改用住宅 IP 商家。

    HostDare 能自建邮局发邮件吗？ #

    不能直接发。本次实测本地 25 端口出站被阻断，远端 25 端口也不可达。需要发送网站通知邮件时，建议使用第三方 SMTP 服务，或者选择 25 端口开放的商家。

    适用场景与选购建议 #

    综合六个维度的实测，HostDare 洛杉矶 CN2 的定位很清晰：用比高端专线低得多的价格，拿到电信 CN2 与联通 9929 的优化回程，三网延迟均衡；代价是移动走普通线路、IP 风控评分偏高、入门款硬件比较普通。

    适合的用户与业务：

    • 面向国内电信、联通访客的个人博客与企业官网
    • 预算有限、又不想忍受普通线路晚高峰丢包的站长
    • 需要美国 IP 访问 ChatGPT、Claude 与 YouTube 的开发环境

    不太适合的用户与业务：

    • 移动用户占比很高、对晚高峰稳定性要求严格的网站
    • 电商、社媒等对 IP 风控评分敏感的账号运营
    • 需要 25 端口自建邮局，或需要较大存储空间的业务

    HostDare 支持支付宝付款，新购订单提供 3 天退款期，搭配商家页的循环优惠码，试错成本可控。现售 CSSD1 年付 60.99 美元，内存与硬盘都比本次测试的早期机型更充裕。
