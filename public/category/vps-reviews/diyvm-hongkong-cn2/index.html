    测试机型与测试环境 #

    本次测试的实例为 DIYVM 香港云 2G 套餐，新用户超级会员价月付 39 元。以下配置均以系统内 lscpu、free 与 df 命令的实际识别结果为准，而非套餐页上的标称值：

    • 处理器：AMD EPYC 7H12 64-Core，分配 2 个 vCPU（KVM 虚拟化）
    • 内存与存储：1.9GB 可用内存，20GB 系统盘加 50GB 数据盘（挂载于 /www）
    • 网络：独立 IPv4，归属 AS132813 HK AISI CLOUD COMPUTING，未分配 IPv6
    • 测试系统：Ubuntu 24.04.1 LTS，内核 6.8，默认 cubic 拥塞控制，未开启 BBR

    所有测试于 2026 年 7 月 10 日完成，延迟、丢包与带宽部分集中在 20:50 至 21:20 的国内晚高峰时段采集，尽量还原真实访客在一天中最拥堵时段的使用环境。

    国内三网延迟实测 #

    对香港机器而言，延迟是第一考核指标。我们使用 Tcptest 调用全国 116 个监测节点，覆盖各省电信、联通与移动骨干网，对这台实例发起了 ICMP 延迟测试：

    全国地图几乎一片深绿，三网平均延迟分别为电信 48ms、联通 51ms、移动 46ms。华南地区平均仅 22ms，广东佛山电信低至 9ms，深圳联通 12ms，广州移动 17ms，基本等同于访问国内机房。

    个别联通节点出现了异常高值，例如内蒙古呼和浩特联通 286ms、贵州贵阳联通 200ms。同样走联通线路的深圳节点只有 12ms，因此这更像是单个监测点的问题，而非整体线路缺陷。

    我们另外从服务器直接 Ping 上海电信骨干节点 202.96.209.133，4 次平均延迟 28.3ms，抖动仅 0.07ms，华东电信用户的访问体验同样相当扎实。

    晚高峰持续丢包监测 #

    单次 Ping 只能说明瞬时状态，真正决定建站体验的是晚高峰的持续稳定性。我们在 20:53 至 21:00 期间，从 13 个国内节点对实例连续发起 100 次 Ping：

    全部 13 个节点的丢包率均为 0%，覆盖电信、联通、移动以及腾讯云、阿里云等云厂商出口。江苏三网平均延迟在 38ms 到 41ms 之间，上海腾讯云平均 32ms，成都与重庆平均约 57ms，最差单次也只有 66ms 到 69ms。

    抖动方面，大部分节点的标准差维持在 1ms 到 3ms 之间，仅重庆腾讯云达到 4.5ms。需要说明的是，这 13 个节点分布在华东、华南与西南，没有覆盖北方地区。

    三网回程路由追踪 #

    很多商家宣传的“CN2 直连”只覆盖电信一家，联通和移动用户实际走什么线路，需要逐条追踪才能看清。我们使用 Backtrace 对北京、上海、广州、成都四地三网进行了回程检测：

    结果比较清晰：上海、广州、成都三地电信均走电信 CN2 优质线路回国，三网联通全部走联通 4837 普通线路，而移动方向则经由电信 163 骨干网回程，并非移动自家的 CMI 线路。

    值得注意的是北京电信节点同样走了联通 4837，说明这台机器的电信 CN2 优化主要覆盖华东、华南与西南地区。为进一步确认电信方向的质量，我们追踪了上海电信到香港方向的去程路由：

    数据包从上海电信 AS4811 出发，经由 59.43 网段的电信 CN2 节点，进入中国电信国际 CTG（AS23764），到这一跳的延迟约为 27ms 到 31ms，中途的 100% 丢包仅出现在不响应 ICMP 的节点上。

    结合前面的延迟与丢包数据，移动和联通虽然没有走精品线路，但香港物理距离足够近，普通线路的实际表现依然很好。对晚高峰质量要求极高的北方用户需要知道这一点。

    CPU 单核得分 1,552 events/s，双核多线程得分 3,102 events/s，几乎是完美的线性翻倍，说明两个 vCPU 没有出现明显的资源争抢，日常跑 WordPress、反向代理或轻量 API 都很从容。

    解读磁盘数据前需要先说明测试方法：FIO 采用 psync 引擎、单队列深度运行，4K 随机写未绕过系统缓存，1M 顺序写也只用了 0.4 秒，很可能同样命中了宿主机缓存。

    因此 75.5k 的随机写 IOPS 和 1,290 MiB/s 的顺序写，更多反映的是缓存速度。4K 随机读 1,136 IOPS、平均延迟约 0.6ms，则是云盘在单队列下的正常水平，日常建站完全够用。

    带宽与下载速度 #

    带宽部分我们同时使用了 Bench.sh 全球节点测速与家庭宽带 iperf3 实测。

    Bench.sh 三轮磁盘写入测试平均 499 MB/s。网络测速中，实例到香港、台北、东京等亚太节点的上传速度在 830 到 905 Mbps 之间，到苏州、宁波等国内节点约为 510 到 530 Mbps。

    下载方向则全部稳定在 47 到 55 Mbps，呈现非常明显的入站限速特征。对建站而言这一点影响不大，访客浏览网页消耗的是服务器出站带宽，只有频繁从外部拉取大文件时才会感受到限制。

    我们还用一条 100Mbps 的电信家庭宽带，通过 iperf3 反向模式从服务器下载数据，10 秒内平均速度达到 114 Mbps，重传次数为 0，直接跑满了家宽上限。

    需要说明的是，套餐页标注的带宽为 5Mbps，而本次在晚高峰实测中并未看到 5Mbps 的出站限速。不过商家只对标称带宽做出承诺，长期业务的容量规划仍建议按标称值保守估算。

    IP 属性与流媒体解锁 #

    最后我们检测了这台实例的 IP 质量与常见服务解锁情况。IP 质量部分使用 IPQuality 脚本，汇总了 Maxmind、IPinfo、Scamalytics 等多个数据库的判定：

    该 IP 在 Maxmind 中被识别为香港注册、香港使用的原生 IP，但各大数据库的使用类型均标记为机房。风险评分整体很低，Scamalytics 与 AbuseIPDB 均为 0 分，IP2Location 仅 3 分。

    唯一的例外是 IPQS 给出了 75 分的可疑评级，原因是它将该 IP 判定为代理与 VPN。对注册风控严格的平台账号来说，这一点值得留意，普通建站则基本不受影响。

    邮件方面，本地 25 端口出站可用，能够连通 Gmail、Outlook、Yahoo、Apple、QQ、Mail.ru、163 与新浪邮箱，AOL、GMX、Mail.com 与搜狐不通，439 个 IP 黑名单数据库中没有任何一个将其列入黑名单，自建通知邮件或轻量邮局是可行的。

    流媒体方面，Netflix、Disney+、YouTube 与 Prime Video 在 IPQuality 中均被判定为原生解锁香港区，Dazn 同样可以解锁，Netflix 优选 CDN 也位于香港。不过 Spotify 与 TVBAnywhere+ 未能解锁。

    AI 服务方面，由于 OpenAI、Google 与 Anthropic 均未向香港地区提供服务，ChatGPT 仅能通过手机 App 使用，Gemini 不可用，Claude 也被跳转到地区不可用页面。

    常见问题解答 #

    DIYVM 香港是 CN2 GIA 线路吗？ #

    Backtrace 只能识别出电信 CN2，无法区分 GIA 与 GT。本次实测中，上海、广州、成都三地电信回程走 CN2，北京电信则走联通 4837，因此不建议把它当作全国三网 CN2 GIA 线路来看待。

    联通和移动用户访问体验怎么样？ #

    联通回程走 4837，移动经电信 163 回程，都不是精品网。但由于香港距离近，联通全国平均延迟 51ms、移动 46ms，晚高峰也没有丢包，华南与华东的联通、移动用户访问依然流畅。

    标称 5Mbps 带宽实际能跑多少？ #

    本次晚高峰实测中，出站到亚太节点达到 830 Mbps 以上，家宽 iperf3 下载跑满 100Mbps，入站则稳定在 50Mbps 左右。实际速率可能随母机负载变化，规划业务仍应以标称带宽为准。

    能解锁 Netflix，能用 ChatGPT 吗？ #

    Netflix、Disney+、YouTube 与 Prime Video 均可解锁香港区。ChatGPT 仅能通过手机 App 使用，Gemini 与 Claude 不可用，有 AI 服务需求的用户建议选择美国或日本机房。

    25 端口能用来发邮件吗？ #

    可以。本次实测 25 端口出站可用，能连通 Gmail、Outlook、QQ、163 等主流邮箱（AOL、GMX、Mail.com 与搜狐不通），IP 也未被任何黑名单数据库收录，适合自建通知邮件或轻量邮局。

    适用场景与选购建议 #

    综合六个维度的实测，DIYVM 香港云 2G 的定位非常清晰：它把国内三网延迟和晚高峰稳定性做得很扎实，硬件也足以支撑日常建站，主要的短板在于回程线路只覆盖了电信方向。

    适合的用户与业务：

    • 面向国内访客的免备案个人博客、企业官网与轻量电商前台，尤其是华南与华东访客
    • 对晚高峰稳定性要求高、但流量规模不大的 API 服务与管理后台
    • 需要观看香港区流媒体内容，或需要 25 端口自建通知邮件的轻度使用场景

    不太适合的用户与业务：

    • 主要访客来自北方，或对联通、移动回程有明确精品网要求的业务
    • 对 IP 风控评分要求严格的平台账号运营，以及需要稳定入站大带宽的下载类业务
    • 需要访问 ChatGPT、Gemini、Claude 等 AI 服务的开发与自动化场景
