    ColoCrossing 是很多美国廉价 VPS 背后的机房运营商，自家也直接出售云服务器，主打低月付与大流量。水牛城机房位于美东，到国内的距离比美西远得多。

    测试机型与测试环境 #

    本次测试的实例为 ColoCrossing 纽约州水牛城机房的 1核1G 机型。以下配置均以系统内 lscpu、free、df 与 Bench.sh 的实际识别结果为准，而非套餐页上的标称值：

    • 处理器：Intel Xeon E5-2683 v4 @ 2.10GHz，分配 1 个 vCPU（KVM 虚拟化）
    • 内存与存储：990MB 内存，另有 1.5GB Swap，25GB 系统盘
    • 网络：独立 IPv4，归属 AS36352（ColoCrossing 网络），未分配 IPv6
    • 测试系统：Ubuntu 22.04.1 LTS，内核 5.15，默认 cubic 拥塞控制，未开启 BBR

    所有测试于 2025 年 9 月 17 日完成，解锁与 IP 检测在北京时间上午 11:00 前后进行。本次没有保存持续丢包监测截图，也未进行内存吞吐与 FIO 顺序读写测试，对应内容不再展示。

    国内三网延迟实测 #

    我们使用 ITDOG 调用全国 163 个监测节点，对这台实例发起了三网 ICMP 延迟测试：

    全国平均延迟为 232ms，三网分别为电信 232ms、联通 217ms、移动 249ms，联通反而是三网中最快的。最快的是中国台湾 178ms 与上海联通 182ms，最慢的西藏拉萨移动达到 295ms。

    地图上只有华东与华中部分省份进入 200ms 以内，大部分地区在 200ms 到 250ms，新疆超过 250ms。这是美东机房的物理距离决定的，比美西机器普遍慢 40ms 到 60ms。

    三网回程路由追踪 #

    我们使用 Backtrace 对北京、上海、广州、成都四地三网进行了回程检测：

    四地电信全部走电信 163，联通全部走联通 4837，移动全部走移动 CMI，均为普通线路。为了看清美东机器的回国路径，我们又用 tracepath 分别追踪了三网各一个目标地址。

    追踪结果显示，三网数据包都先经 Telia、GTT 与 Cogent 等美国骨干网，从水牛城一路西行到圣何塞、洛杉矶，再接入电信 163、联通 4837 或移动 CMI 跨太平洋回国，抵达目标时延迟在 224ms 到 334ms 之间。

    换句话说，美东机器回国需要先横穿美国大陆，仅到达圣何塞就已经用掉 56ms 左右，这也是它比美西机器慢的主要原因。面向国内访客的网站，建议在前端接入 CDN。

    E5-2683 v4 是一颗 2016 年发布的服务器处理器，单核 Sysbench 得分 751 events/s。跑静态网站、监控探针、反向代理或轻量 Docker 容器足够，编译和高并发数据库会比较吃力。

    磁盘测试采用 libaio 引擎与单队列深度，未开启 direct 参数，4K 随机写 12.9k IOPS 含有系统缓存，随机读 2,551 IOPS 更接近磁盘实际水平。Bench.sh 三轮写入平均 303 MB/s，属于普通 SSD 的表现。

    带宽与下载速度 #

    带宽部分我们使用 Bench.sh 对全球多个测速节点进行了上传与下载测试：

    本地测速节点上传 1,018 Mbps、下载 883 Mbps，基本跑满 1Gbps 端口。远程方向的下载普遍在 400 到 580 Mbps，上海节点下载 530 Mbps，巴黎与阿姆斯特丹延迟不到 100ms。

    上传到远端则明显偏弱，上海 113 Mbps、新加坡 44 Mbps，香港节点上传 4 Mbps、下载仅 0.2 Mbps，延迟高达 445ms。配合每月 20TB 的流量，它更适合做美欧方向的数据中转与备份。

    IP 属性与流媒体解锁 #

    最后我们检测了这台实例的 IP 质量与常见服务解锁情况。IP 质量部分使用 IPQuality 脚本，汇总了 Maxmind、IPinfo、Scamalytics 等多个数据库的判定：

    该 IP 在 Maxmind 中被识别为美国纽约州水牛城的原生 IP，各大数据库的使用类型均标记为机房。IP2Location、AbuseIPDB 与 Cloudflare 为低风险，但 Scamalytics 给出 27 分中风险。

    IPQS 给出 75 分可疑评级，并将其判定为代理与 VPN，ipapi 也标记了 VPN。对需要注册风控严格平台账号的用户来说，这台机器的 IP 并不合适。

    邮件方面，本地 25 端口显示被占用，远端 25 端口不可达，无法直接自建邮局发信。在 439 个有效黑名单数据库中，有 19 个已标记、3 个将其列入黑名单。

    流媒体方面，YouTube Premium、Amazon Prime Video 与 TikTok 均可解锁美区，TVBAnywhere+ 也可使用。但 Netflix 只能观看自制剧，Disney+ 显示 IP 被封禁，Spotify 与 Reddit 也无法使用。

    AI 服务方面，ChatGPT、Google Gemini 与 Claude 均能正常访问，满足日常的 AI 工具使用需求。

    常见问题解答 #

    ColoCrossing 纽约到国内速度怎么样？ #

    偏慢。全国三网平均 232ms，三网回程都是普通线路，而且需要先横穿美国大陆到西海岸再跨太平洋。面向国内访客建站必须搭配 CDN，否则首屏加载会很慢。

    ColoCrossing 能看 Netflix 吗？ #

    只能看 Netflix 自制剧，Disney+ 被封禁。YouTube Premium 与 Prime Video 可以解锁美区。如果流媒体是主要需求，建议选择解锁更完整的机器。

    ColoCrossing 能用 ChatGPT 吗？ #

    可以。本次实测 ChatGPT、Google Gemini 与 Claude 均可正常访问。但 IPQS 将该 IP 判定为代理与 VPN，长期使用时可能偶尔遇到额外的人机验证。

    ColoCrossing 20TB 流量有什么用？ #

    适合做文件备份、数据中转、下载机或面向欧美的大流量服务。实测本地带宽能跑满 1Gbps，但到亚洲方向的上传速度较慢，不适合给国内用户分发大文件。

    适用场景与选购建议 #

    综合五个维度的实测，ColoCrossing 水牛城机房的定位非常清晰：它用很低的月付价格提供了千兆端口与 20TB 月流量，适合当作美国工具机，但国内网络与 IP 质量都不是它的强项。

    适合的用户与业务：

    • 需要大流量的文件备份、数据中转、下载与离线任务
    • 面向美国东部与欧洲访客的网站、API 与反向代理网关
    • 预算有限、需要一台长期在线的美国 Linux 练手机

    不太适合的用户与业务：

    • 主要访客在国内、对延迟敏感的网站与远程桌面
    • 需要 Netflix、Disney+ 等完整流媒体解锁的用户
    • 对 IP 风控评分要求严格的平台账号，或需要 25 端口自建邮局的用户

    需要注意的是，ColoCrossing 的退款条款并不明确。
