    Vultr 怎么样？全球 34 机房按小时计费云服务商解析 #

    Vultr全球 34 机房 / 按小时计费云
    访问 Vultr 官方网站
    成立时间 / 资历 2014 年 (已稳健运营)
    运营主体 / 注册地 美国（The Constant Company, LLC）
    起步参考价格 $2.5/月

    Vultr 是一家美国的国际云服务商，在中文站长和开发者圈子里知名度很高。它的核心卖点不是某条精品线路，而是全球 34 个机房、按小时计费与随开随删的使用方式。

    和一般 VPS 商家按月或按年买断不同，Vultr 更像一个缩小版的公有云：开一台服务器只需几十秒，用完直接销毁，只为实际运行的小时数付费。对需要频繁换机房、换 IP 或做短期测试的人来说，这种模式非常灵活。

    下面结合官网公开信息与我们对西雅图机房的实测数据，把这家商家梳理清楚。

    品牌背景与全球机房版图 #

    Vultr 成立于 2014 年，总部位于美国佛罗里达州西棕榈滩，运营主体为 The Constant Company, LLC，官网页脚也注明 VULTR 是该公司的注册商标。至今已运营超过十年。

    官网目前列出了 34 个云数据中心，覆盖北美、南美、欧洲、亚洲、澳洲与非洲六大洲。美国本土有洛杉矶、西雅图、硅谷、芝加哥、达拉斯、纽约、迈阿密等十余处，亚洲则有东京、首尔、新加坡与印度班加罗尔等节点。

    产品线早已不止 VPS，还包括裸金属服务器、云 GPU、托管 Kubernetes、托管数据库、对象存储与 CDN 等，近两年重点发力 AI 算力业务。对普通用户来说，最常用的仍是 Cloud Compute 系列云服务器。

    付款方式对国内用户很友好。官方 FAQ 明确支持 Visa、万事达等信用卡，以及支付宝、银联、PayPal 和 BitPay 加密货币，采用预充值余额的方式扣费，国内用户直接用支付宝充值即可。

    按小时计费机制详解 #

    Vultr 最大的特色是计费方式，下单前一定要先理解清楚，否则很容易多花钱：

    计费规则具体说明
    最小计费单位1 小时，不足 1 小时按 1 小时计算
    每月封顶Cloud Compute 等多数产品每月最多收 672 小时，即标价月费
    关机仍收费只要服务器没有销毁，关机状态也照常计费
    扣费方式每小时从账户余额累计扣费，每月 1 日出账单

    672 小时相当于 28 天，所以一个 30 天的月份里，跑满整月也只收标价月费，不会因为大月多收钱。这也是为什么 Vultr 标价同时写着月价和小时价。

    需要特别注意“关机仍收费”这一条。很多新手以为关机就不扣钱了，结果余额照样被扣光。想停止计费，必须在控制台把服务器彻底销毁（Destroy），重要数据要先做快照或备份。

    这种模式最适合三类人：需要临时开机做测试的开发者、想在不同国家机房之间对比延迟的站长，以及开机遇到 IP 不通、想直接销毁重开换 IP 的用户。

    4. 其他产品线一览 #

    除了上述共享 CPU 的云服务器，Vultr 还有几条产品线可以按需选择：

    • Optimized Cloud Compute：独享 AMD EPYC 核心与 NVMe，没有“邻居”争抢资源，1 核 4G 每月 $30 起，适合生产环境；
    • VX1 云服务器：新一代独享 CPU 实例，支持高性能块存储启动，按实际小时数计费，不受 672 小时封顶；
    • 裸金属服务器：单租户物理机，E3-1270 起步每月 $120，同样支持按小时计费；
    • 云 GPU：提供 NVIDIA 与 AMD 多种 GPU，按小时计费，适合 AI 推理与训练。

    硬件性能与网络线路实测 #

    为了验证 Vultr 的实际表现，我们在西雅图机房开通了一台 Regular Performance 1 核 1G 机型，重点考察硬件性能与国内三网线路两个维度。逐项的原始数据将在测评专栏单独发布。

    单核 729 分在我们测过的机器里属于偏低水平，同价位的 GreenCloud Ryzen 机型约为它的 9 倍。顺序读写在 350~400MB/s 左右，4K 随机读写约 4400 IOPS，属于普通 SATA SSD 的水平。

    这说明 Regular Performance 更适合跑静态网站、代理、监控探针这类轻负载业务。如果要跑 WordPress 加数据库，建议加 1 美元升级到 High Performance 或 High Frequency，换上新一代处理器与 NVMe 硬盘。

    2. 国内三网延迟与丢包 #

    测试机所属网络为 AS20473，回国走普通国际线路，并非 CN2 GIA 等优化线路。从上海电信出发的路由经美国圣何塞再到西雅图。我们在中午时段通过 319 个国内监测点进行了一次延迟采样：

    全国平均延迟 219ms，电信 208ms、联通 275ms、移动 188ms，最快的上海移动为 129ms。移动方向表现最好，联通则明显偏慢，这是美西普通线路的常见情况。

    我们又对国内多个节点进行了 100 次连续 ping，观察丢包情况：

    测试时段各节点丢包率多数在 0%~5% 之间，个别达到 7%，整体平均约 2%，比我们预想的要稳定。不过这次采样避开了晚高峰，晚上的丢包率会有所上升，对稳定性要求高的业务要留出余量。

    综合来看，Vultr 的价值在于全球机房覆盖与按小时计费的灵活性，而不是回国线路或入门机型的硬件。把它当作多地区部署、开发测试与临时换 IP 的工具，才能真正发挥它的优势。

    使用前需要注意的几点 #

    Vultr 的使用门槛不高，但计费方式和网络环境上有几点和普通 VPS 商家不太一样，结合实测情况给出几条提醒：

    • 关机不等于停止计费：服务器只要没有销毁就会一直扣费，不用的机器一定要在控制台 Destroy，块存储、自动备份等附加资源也会单独计费；
    • 25 端口默认阻断：测试机的 25 端口出站处于阻断状态，需要自建邮局发信的用户要先向官方提交工单申请；
    • IP 为机房属性：测试机 IP 被各数据库识别为数据中心 IP，Netflix 仅能看自制剧、Disney+ 无法访问，不适合跨境电商养号；
    • AI 服务部分可用：ChatGPT 与 Claude 可以正常访问，Google Gemini 则无法使用，有这类需求的用户要留意；
    • 新 IP 可能不通：热门机房的 IP 偶尔会遇到国内无法访问的情况，可以直接销毁重开，按小时计费的损失很小。

    此外，Vultr 的控制台与工单系统均为英文，但界面简洁直观，部署、快照、换机房重开等操作几分钟就能上手。

    总结与选购建议 #

    综合来看，Vultr 是一家定位清晰的国际云服务商。它不以回国线路取胜，核心价值在于十余年的运营记录、覆盖六大洲的 34 个机房，以及按小时计费、随开随删的使用方式，再加上支付宝充值，对国内用户相当友好。

    如果你是开发者，需要临时测试环境、多地区部署或者频繁更换 IP，Vultr 几乎是最省心的选择之一。新用户可以先用体验金把各地区机房都试一遍，再挑延迟最合适的长期使用，建站的话直接选 High Performance 或 High Frequency。

    如果你需要国内访问快、晚高峰丢包低的直连线路，这里就不是最优解了。高端直连需求建议看 DMIT 或 搬瓦工，同样按小时计费、价格更低的选择可以看看 CloudCone。
