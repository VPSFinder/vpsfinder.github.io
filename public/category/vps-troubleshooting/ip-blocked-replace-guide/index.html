    先判断是不是被墙 #

    “连不上”不一定是被墙。本地网络故障、服务器防火墙没放行端口、商家机房临时维护，表现出来都是连不上。判断的关键是对照检测：同一个 IP，从国内和海外分别测试，看结果是否不同：

    • 国内检测：用国内在线 Ping 与 TCPing 工具；
    • 海外检测：用海外节点或商家后台控制台；
    • 同时测端口：至少测 SSH 端口与网站端口。

    国内在线测速工具（如 ITDOG）可以从全国多个节点同时发起 Ping 与 TCPing，海外则可以用 ping.pe 这类全球测速站，或直接登录商家后台的 VNC 控制台。两边结果放在一起对比，基本就能判断出问题在哪一侧。

    下图是我们测评 JustHost 洛杉矶时用 ITDOG 做的全国 Ping 检测，IP 正常时，160 个监测点都能返回延迟，地图按延迟高低着色。如果 IP 被墙，地图上会大面积显示红色的“超时”：

    做 TCPing 检测时，界面和结果的看法基本相同，只是测的是端口能否连通。一般测 22 端口就够了，如果你改过 SSH 端口，就填改过的端口号，网站则另外测 80 和 443 端口。

    常见现象与原因对照 #

    下表整理了几种常见的检测结果组合。需要注意的是，有些商家默认禁止 Ping，单看 Ping 不通容易误判，一定要同时测 TCP 端口，再下结论：

    现象国内检测海外检测可能原因
    全部不通Ping 与端口都不通正常IP 被墙
    只有 Ping 不通端口正常端口正常禁 Ping，不影响使用
    个别端口不通部分端口失败正常端口被阻断
    国内外都不通不通不通机器故障或防火墙
    部分省份不通个别地区失败正常线路故障或区域阻断

    只有第一种情况才是典型的 IP 被墙，这时候在服务器里怎么折腾都没用，只能换 IP。如果国内外都不通，先进 VNC 控制台检查系统防火墙和网络配置，或者给商家提交工单询问机房状态。

    被墙后的四种处理办法 #

    确认 IP 被墙后，处理办法取决于你买的是哪家商家、哪种计费方式。下面四种办法按适用面从窄到宽排列，有退款期的新机可以优先考虑最后一种，避免把时间耗在一台机器上。

    提交工单申请换 IP #

    部分商家会为新开通且 IP 不通的机器免费换一次 IP，比如 RackNerd。提交工单时附上国内外对照检测的截图，说明 SSH 端口从国内无法连接，处理会更快。不少商家对已使用一段时间的机器换 IP 要单独收费。

    迁移机房自动换 IP #

    JustHost 的控制台支持把整机迁移到其他机房，迁移完成后会分配新机房的 IP。这种方式不需要等工单，数据也会一并迁移，缺点是新机房的线路和延迟可能与原机房不同，迁移前最好先查一下目标机房的线路。

    需要注意的是，并不是所有能迁机房的商家都允许被墙后迁移。搬瓦工 KiwiVM 的迁机房功能要求当前 IP 没有被墙，IP 一旦被墙就不能再通过迁移换 IP，所以它不能当作被墙后的补救办法。

    销毁重开换新 IP #

    CloudCone、Vultr 这类按小时计费的云服务器，删掉实例再新建一台，通常就会分配到新 IP，只损失几美分到几毛钱。迁移前记得先做好备份或快照，新实例建好后再把数据和配置恢复过去。

    退款期内直接退款 #

    如果商家有无理由退款政策，新机开通后发现 IP 不通，直接申请退款再换一家也是办法。JustHost 支持 15 天退款，DMIT 支持 3 天全额退款，各家的退款条件不同，申请前请以官网条款为准。

    搬瓦工虽然有 30 天退款政策，但同样要求 IP 没有被墙，被墙的机器不能退款。所以买搬瓦工之后，第一件事就是从国内检测连通性，确认 IP 正常后再部署业务，有问题尽早联系客服。

    常见问题解答 #

    怎么判断 VPS 的 IP 是不是被墙了？ #

    用国内在线 Ping 与 TCPing 工具测试 IP 和 SSH 端口，再用海外节点或商家控制台测试同一个 IP。国内全部不通、海外正常，基本可以确认被墙；国内外都不通，问题多半出在机器或防火墙。

    只有 Ping 不通算被墙吗？ #

    不算。有些商家或系统默认禁止 Ping，只要 SSH 端口和网站端口从国内能正常连接，就不影响使用。判断是否被墙时，一定要以 TCP 端口的检测结果为准，不要单看 Ping。

    换了 IP 还会再被墙吗？ #

    有可能。如果是整个 IP 段被封，同一机房换到的新 IP 可能还是不通，这时候换到其他机房效果更好。所以 JustHost、Vultr 这类机房多的商家，在换 IP 这件事上的容错空间更大。

    网站被墙了，数据会丢吗？ #

    不会。IP 被墙只影响国内访问，服务器本身仍在运行，数据也都在。可以通过商家后台的 VNC 控制台或海外网络登录服务器，先做好备份，再换 IP 或迁移机房，最后把域名解析改到新 IP。

    买之前能不能避开被墙的 IP？ #

    不能完全避开，但可以降低概率。买之前用商家提供的测试 IP 从国内测一下连通性，优先选有退款期或支持换 IP 的商家；开通后第一时间做对照检测，发现问题在免费换 IP 或退款期内处理。
