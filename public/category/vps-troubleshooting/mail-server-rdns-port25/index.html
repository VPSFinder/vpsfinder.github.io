    VPS自建邮件进垃圾箱怎么办：25端口检测、rDNS设置与开放25端口的VPS #

    先判断是哪一环出了问题 #

    “发不出去”和“进垃圾箱”是两类问题。前者多半是 25 端口被封，信根本没离开服务器；后者说明信已经送达，只是被对方的反垃圾系统扣了分。动手修之前，可以先按下面三步依次检查：

    • 测 25 端口：从服务器连接外部邮局的 25 端口；
    • 查反向解析：确认 IP 的 PTR 记录指向邮件域名；
    • 看邮件评分：把测试信发到评分工具查扣分项。

    测 25 端口最简单的办法，是在服务器上执行 nc -vz gmail-smtp-in.l.google.com 25，或者用 telnet 连接同一地址的 25 端口。能看到连接成功或 220 开头的欢迎信息，说明出站正常；一直超时，基本就是被商家封了。

    我们在测评中使用 IPQuality 脚本做同样的检测，它会依次连接十几家主流邮箱的 25 端口。下图是 GreenCloud 洛杉矶的结果，绿色表示能连通，红色表示不通，最后一行是 IP 在黑名单数据库中的收录情况：

    查反向解析可以执行 dig -x 你的IP +short，返回的应该是你的邮件主机名，例如 mail.example.com。如果返回商家默认的主机名或者为空，说明还没设置 rDNS，对方邮局会因此给信件扣分甚至直接拒收。

    邮件进垃圾箱的处理办法 #

    确认问题所在之后，可以按下面的顺序逐项处理。前三项是自建邮局的基本配置，缺一项都很容易进垃圾箱；后两项针对 IP 信誉和端口被封的情况，按需要选用。

    确认 25 端口能出站 #

    25 端口是邮局之间投递邮件的端口，大多数商家为了防止垃圾邮件默认封锁。有的商家可以提交工单说明用途后申请解封，但审核标准不一，新账户通常很难通过，买之前选好 25 端口开放的商家最省事。

    设置 rDNS 反向解析 #

    反向解析由 IP 的所有者，也就是 VPS 商家来设置，不是在你的域名 DNS 里添加。部分商家的控制面板可以自助修改 PTR，其余需要提交工单。设置前先给邮件主机名添加指向该 IP 的 A 记录，两边对上才算有效。

    配好 SPF、DKIM 与 DMARC #

    这三条都是添加在域名 DNS 里的 TXT 记录。SPF 声明哪些 IP 可以代表域名发信，DKIM 给信件加上签名，DMARC 告诉对方验证失败时怎么处理。主流邮局程序安装后都会生成 DKIM 公钥，照着提示添加即可。

    配置完成后，可以把测试信发到 mail-tester 这类评分工具，它会列出 SPF、DKIM、rDNS 与黑名单的检测结果和扣分项。一般做到 9 分以上，发到 Gmail、Outlook 等主流邮箱就不太容易进垃圾箱了。

    检查黑名单并控制发信量 #

    新 IP 可能曾被上一任用户用来群发，已经进了某些黑名单。可以用 MXToolbox 等工具查询 IP 的收录情况，被收录的话按对应黑名单的流程申请移除，或者直接换一个干净的 IP，再从少量发信开始逐步提高发信量。

    端口不通就用 SMTP 中继 #

    如果商家不开放 25 端口，或者 IP 信誉怎么也养不起来，可以让邮局程序通过第三方 SMTP 中继服务发信，走 587 或 465 端口提交，收信仍然由自己的服务器负责。网站的注册验证、通知邮件也可以直接接入中继服务。

    常见问题解答 #

    怎么知道 VPS 的 25 端口有没有被封？ #

    在服务器上执行 nc -vz gmail-smtp-in.l.google.com 25，或用 telnet 连接同一地址的 25 端口。能连上说明出站正常，一直超时基本就是被商家封了。只连不上个别邮箱，则可能是对方屏蔽了这个 IP。

    rDNS 在哪里设置？ #

    rDNS 由 IP 所在的商家设置，不在域名 DNS 里。部分商家的控制面板可以自助修改 PTR 记录，其余需要提交工单。设置前先给邮件主机名添加 A 记录，PTR 与 A 记录互相对应才有效。

    25 端口能申请解封吗？ #

    部分商家支持提交工单说明用途后申请解封，但审核标准不一，新账户和低价套餐通常很难通过。与其买了再申请，不如直接选择我们测评中 25 端口可用的商家，或者改用 SMTP 中继发信。

    配好了 rDNS 和 SPF 还是进垃圾箱怎么办？ #

    先把测试信发到 mail-tester 这类评分工具，看还有哪些扣分项，常见的是缺少 DKIM 签名或 IP 在黑名单中。其次是新 IP 信誉低，需要从少量发信开始逐步增加，内容也避免使用大量链接和营销词汇。

    自建邮局和用企业邮箱哪个好？ #

    自建邮局成本低、邮箱数量不限，但需要自己维护 IP 信誉和服务器安全。如果只是几个人日常收发、对送达率要求很高，企业邮箱更省心；需要大量邮箱账户或网站批量通知时，自建更划算。
